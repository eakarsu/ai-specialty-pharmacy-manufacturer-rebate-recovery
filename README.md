# Specialty Pharmacy Manufacturer Rebate Recovery

Capture manufacturer rebates and service fees earned through specialty-drug volume, outcomes, and contracted data delivery.

**Primary buyer:** Specialty pharmacies and health systems. **Evidence:** manufacturer agreements, NDCs, dispenses, patient eligibility, adherence measures, data submissions, tier guarantees, invoices, credits, and payments.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Manufacturer agreement library
- NDC product registry
- Eligible dispense ingestion
- Patient program qualification
- Volume tier calculation
- Market-share calculation
- Adherence measure validation
- Outcome guarantee evidence
- Data submission SLA
- Invoice generation
- Manufacturer deduction review
- Credit memo reconciliation
- Dispute package
- Cash collection tracking
- Program drug economics

Run `./start.sh`, then open <http://127.0.0.1:4647>. API: `5647`.
